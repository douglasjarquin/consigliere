Supervision protocol

One protocol: the bounded foreground checkpoint. One backstop: the Stop hook. Soldiers work unattended; nothing lands without the boss.

Bounded foreground checkpoint

The consigliere supervises every soldier through a single, bounded, foreground checkpoint rather than a background poller. Each checkpoint reads herdr’s native agent status for the soldier’s workspace, so busy detection never depends on scraping a pane.

dispatchA task is described, a project named, a workspace created, a soldier spawned with the root harness.
checkpointBounded in time. The consigliere reads status, reviews progress, and either continues, redirects, or lands.
landA PR is brought back for the boss’s word. yolo lets the consigliere answer routine review decisions on its own; landing is still the boss’s call.
backstopThe Stop hook: if a soldier stops outside the protocol, the hook catches it so no work goes silently dark.

Delivery posture

Each project carries a standing delivery posture, set when the project is added. Each task’s actual delivery mode is decided when the work is dispatched. The optional no-mistakes delivery pipeline (and its Go sibling, made) can gate a PR before it is opened.

never tears downunlanded work
never worksa repo it does not know about

Turn telemetry

Optional. Documented in docs/; records per-turn timing for a session so long-running supervision can be inspected after the fact.
