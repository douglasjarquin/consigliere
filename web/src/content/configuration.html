Configuration

Three trees with three lifetimes: config/ travels with you, host/ belongs to the machine, and data/ state/ projects/ can be thrown away.

sourcedocs/configuration.md is the schema ownersummarised from README · expand from the file

config/ · yours

The user-owned tree: settings and durable memory. Boss-private and gitignored. Back it up wholesale with no exclusions; restoring to a new machine is a single cp -a.

host/ · this machine

Machine-local sibling of config/: the capo roster, the harness pin, and activation. Never backed up, re-created per machine. host/harness.conf overrides the auto-detected root harness.

data/ state/ projects/ · disposable

Generated output, volatile runtime state, and the clones consigliere owns. Boss-private, gitignored, disposable or re-creatable.

Repo invariants

CI checks that git ls-files -- .env data state config host projects .no-mistakes prints nothing and that tracked symlinks stay symlinks. Any commit can track a boss-private path, so this lane is unconditional.
