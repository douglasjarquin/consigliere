Projects

Consigliere never works a repo it does not know about. A project is a registered clone with a standing delivery posture.

Adding one

Tell the consigliere to add or create a project. It owns three things: the clone into projects/, the registry entry, and the project’s standing delivery posture.

boss › add github.com/acme/gateway as a project, deliver via PR with no-mistakes
consigliere › cloned into projects/gateway · registered · posture: pr + no-mistakes

Delivery posture

The posture is the default for the project. Each task’s actual delivery mode is decided when the work is dispatched, so a hotfix can land differently from a feature without changing the registry.

prSoldier work comes back as a pull request for the boss’s word.
pr + gateThe PR is opened only after the delivery pipeline (no-mistakes, or made) passes on the committed SHA.
yoloThe consigliere answers routine review decisions itself. Landing is still the boss’s call.

Where it lives

projects/Clones. Boss-private, gitignored, re-creatable.
config/The registry and durable memory about each project.
state/Volatile runtime state for in-flight work.
