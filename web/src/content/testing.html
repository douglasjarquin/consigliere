Testing & CI

Every hosted check has a local twin. Every test belongs to exactly one lane. Lanes run only when a change can affect them.

Local tests

bash tests/<name>.test.sh            # one colocated behavior test
bin/cs-test-run.sh --portable          # every hermetic test, serial

Hosted checks and how to reproduce them

check
reproduce locally
notes
Shell lint
CI=true bin/cs-lint.sh
Pinned ShellCheck. Local default lints changed canonical files plus both directions of the source graph.
Portable behavior
bin/cs-test-run.sh --portable
Hermetic, serial.
Real Herdr behavior
CS_TEST_HERDR_LIVE=1 bin/cs-test-run.sh --herdr
Needs a real herdr and a running default session for the lab tripwire.
Repo invariants
git ls-files -- .env data state config host projects .no-mistakes
Must print nothing; tracked symlinks stay symlinks. Unconditional.
Coverage guard
bin/cs-test-run.sh --check-coverage
Proves every tests/*.test.sh is in exactly one lane.
Dev-tools container
CS_TEST_DOCKER_LIVE=1 bin/cs-test-run.sh --docker
Needs a live Docker daemon.

Lanes

Every tests/*.test.sh belongs to one lane: portable, real-herdr, or the opt-in live-codex / live-claude lanes, which never run in hosted CI and are reported as visibly excluded by the coverage guard.

bin/cs-ci-lanes.sh owns the path-to-lane map and prints the decision for a diff. The gate is a job-level if: rather than a paths: filter, so a skipped lane still reports its check. An undeterminable change set fails open and runs everything.

bin/cs-ci-lanes.sh <base> <head>
bin/cs-ci-lanes.sh --paths-from -      # read a path list from stdin

Workflow contract

.github/workflows/ci.yml runs on pushes to main and PRs into main with least-privilege contents: read and cancellation of superseded runs. The contract is protected by tests/cs-ci-contract.test.sh, which also fails the build when a source site in the canonical set has no # shellcheck source= directive.
