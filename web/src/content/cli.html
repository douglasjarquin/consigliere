CLI · bin/cs-*

Every script is a cs-* file in bin/. Read its header before first use; the header is the contract.

sourcebin/*.sh headerssummarised from README · expand from the file

Machine and session

cs-doctor.shDependency preflight: every tool, its version, the herdr server, GitHub auth, and a suggested install channel per gap. Checks only. Nonzero while anything required fails.
cs-session-start.shRuns at session start. Prints one ordered digest of the operating picture; asks before installing anything.
cs-install-herdr.shInstalls CI’s pinned, SHA-256-verified herdr build. Single owner of the pin. bin/cs-install-herdr.sh ~/.local/bin

Libraries

cs-harness-lib.shThe one thin harness layer for codex and claude.
cs-herdr-lib.shherdr integration; owns CS_HERDR_MIN_PROTOCOL.
cs-deps-lib.shRequired/optional inventory, Python floor, axi version floors and bump policy.

Quality

cs-lint.shShellCheck with a pinned version. Locally lints changed canonical files plus both directions of the source graph; CI=true lints the full set.
cs-test-run.sh--portable (hermetic, serial), --herdr, --docker, --check-coverage (every test in exactly one lane).
cs-ci-lanes.shOwns the path-to-lane map; prints the lane decision for a diff: cs-ci-lanes.sh <base> <head> or --paths-from -
cs-upstream-log.shLedger entry for an editorial Firstmate port.

CI lanes

Shell lint            CI=true bin/cs-lint.sh
Portable behavior     bin/cs-test-run.sh --portable
Real Herdr behavior   CS_TEST_HERDR_LIVE=1 bin/cs-test-run.sh --herdr
Repo invariants       git ls-files -- .env data state config host projects .no-mistakes
Coverage guard        bin/cs-test-run.sh --check-coverage
Dev-tools container   CS_TEST_DOCKER_LIVE=1 bin/cs-test-run.sh --docker

The gate is a job-level if: rather than a paths: filter, so a skipped lane still reports its check. An undeterminable change set fails open and runs everything.
