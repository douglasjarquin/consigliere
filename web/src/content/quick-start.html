Getting started

Quick start

Eight steps from a bare machine to a consigliere that knows your projects. It only detects gaps; it never installs anything behind your back.

Requirements

codex or claude, Python 3.11+, herdr (protocol ≥ 16), jq, git, gh + gh-axi (authenticated).

Optional: the other harness, tasks-axi (backlog), no-mistakes (delivery pipeline), lavish-axi, chrome-devtools-axi, quota-axi.

01

Clone the repo.

git clone https://github.com/douglasjarquin/consigliere.git
02

Install herdr.

Use your own install, or take CI's pinned, SHA-256-verified build. bin/cs-install-herdr.sh is the single owner of that pin; docs/herdr.md documents it.

bin/cs-install-herdr.sh ~/.local/bin
03

Install the rest, then authenticate GitHub.

jq, git, gh, gh-axi, and at least one harness.

gh auth login
04

Check the machine.

bin/cs-doctor.sh reports every dependency, its version, the herdr server, and GitHub auth, and suggests an install channel for each gap. An installed axi tool below its version floor counts as a gap. It exits nonzero while any required check is failing.

bin/cs-doctor.sh
05

Start the herdr server.

Consigliere spawns every soldier into a herdr workspace, so this comes first. Without it the session refuses to dispatch.

herdr
06

From inside a herdr pane, launch the harness.

cd consigliere
codex     # or: claude
07

Let the first session settle.

It runs bin/cs-session-start.sh and reports anything still missing, out of date, or unauthenticated, reading the same inventory and version floors as the doctor. It detects only, and asks before installing anything.

08

Give it a project.

Consigliere never works a repo it does not know about. Tell it to add or create one: it owns the clone into projects/, the registry entry, and the project's standing delivery posture. Each task's actual delivery mode is decided when the work is dispatched.

Then talk to it.

Describe the work in plain language, name the project when it is ambiguous, and it dispatches, supervises, and brings back PRs for your word. AGENTS.md is the always-loaded operating contract (claude loads it via the CLAUDE.md symlink). The root harness is auto-detected: CLAUDECODE=1 ⇒ claude, else codex; host/harness.conf overrides.
