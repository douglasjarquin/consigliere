herdr

The one terminal runtime. Soldiers live in its workspaces; the session refuses to dispatch without it.

sourcedocs/herdr.mdsummarised from README · expand from the file

Requirement

herdr protocol ≥ 16. The floor lives in bin/cs-herdr-lib.sh as CS_HERDR_MIN_PROTOCOL, and the installer reads it.

Install

Use your own install, or take CI’s pinned, SHA-256-verified build. bin/cs-install-herdr.sh is the single owner of that pin.

bin/cs-install-herdr.sh ~/.local/bin

What consigliere uses it for

worktreesWorkspace-per-task replaces the treehouse pool.
agent statusNative busy detection replaces pane-regex.
panesThe consigliere itself runs inside a herdr pane.

herdr
