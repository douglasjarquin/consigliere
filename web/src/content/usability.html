Usability system

The interaction vocabulary for this site and the ones that follow it. Every component here is live. Shared rules: Escape always closes, focus is always visible, nothing moves unless the boss asked it to, and destructive actions take two steps.

TOC scroll-spy #

The sidebar on this page is the live demo. The section nearest the top third of the viewport is current: foreground text, accent dot. Heading anchors show a # that turns accent on hover.

current section: {{ currentTitle }}

Command palette #

Global search over pages and commands. ⌘K opens; arrows move; Enter goes; Esc closes. Never more than eight results. Type nonsense to see the empty state.

Nav drawer #

Below 768px the nav links live here. Slides from the left in 120ms, scrim behind, Esc or scrim closes. Contains the full docs sidebar, not just the top nav.

Shortcut sheet #

Press ? anywhere. Lists every shortcut on the site in two columns. Closes with Esc or ? again.

Popover #

Click-triggered, anchored below the trigger, one per page at a time. For short secondary content: a definition, a menu, a detail. Not for forms.

Tooltip #

Hover or focus, mono, one line, no delay longer than 300ms. Labels an icon or expands an abbreviation. Never holds anything the user must read to proceed.

Requires herdrterminal runtime · protocol ≥ 16 and gh-axiGitHub helper · authenticated · floor gated.

Tabs #

Underlined labels on a hairline, one panel visible. For alternatives of equal weight (install channels). Arrow keys move between tabs. Distinct from the harness switch, which is a setting.

Inline text editor #

Click text to edit it in place, same font, same size. Enter or blur commits; Esc reverts. The field never jumps: the input inherits the text's metrics exactly.

Copyable command #

Every shell snippet carries a copy affordance in its top-right corner. The label changes to copied for two seconds; no toast, no icon swap.

bin/cs-install-herdr.sh ~/.local/bin

Harness switch #

A segmented control that swaps every snippet on the page between codex and claude, and updates the badge in the nav. The choice persists across pages.

Callouts #

Four kinds, told apart by the mono label and the border, never by color. Solid for note and warning; dashed for provisional; struck label for deprecated.

warningWithout a running herdr server the session refuses to dispatch.
provisionalSummarised from the README. Expand from docs/supervision.md.
deprecatedPane-regex busy detection. Replaced by herdr-native agent status.

Disclosure #

For optional depth under a docs section. One line closed, a hairline-bounded block open. Several may be open at once.

So a skipped lane still reports its check instead of hanging pending. An undeterminable change set (force-push, first push, shallow clone) fails open and runs everything.

ShellCheck blames a broken library contract on its consumers. So a changed file pulls in the libraries it sources and the canonical files that source it.

Two-step confirm #

Anything that lands, deletes, or tears down asks once, inline, in the same spot. No modal. The confirm expires after four seconds if ignored.

Run stepper #

A run's states in order. Done states are foreground, the current one is accent with a filled dot, future ones muted. Shared with made, where it shows the gate timeline.

Evidence viewer #

Failed checks as rows: name, rerun count, link. Click a row for the bounded excerpt. External checks are marked and never carry a rerun count.

Live log tail #

A fixed-height code block that follows the newest line. Pausing stops the follow but keeps receiving; a counter shows how many lines arrived while paused. Keeps the last 200 lines.

{{ logText }}
+{{ logPending }} new

Skeleton #

While a page or list streams in. Bars in the line color, pulsing opacity at 1.6s, shaped like the content they stand in for. Never a spinner.

Empty state #

A dashed frame, one serif sentence saying what is absent, one mono action. No illustrations. The palette uses the same shape when nothing matches.

No soldiers in flight.dispatch one →

Status chips #

Soldier and run states. Mono, lowercase, a 6px dot. Only the active state uses the accent.

queued working checkpoint awaiting boss landed stopped · backstop

Toast #

Bottom-left, one at a time, five seconds, dismissable. Only for events that happened somewhere else. Never for confirming the click you just made.

Pager #

Bottom of every docs page: previous on the left in muted, next on the right in foreground, both with the section eyebrow above the title. Follows sidebar order.
